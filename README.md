# GameHub

A browser gaming hub with a growing library of playable games built for the web.

Current playable builds:
- BasketBros Pro
- Spider City Swing
- PowerScaler

Project intent:
- Full original browser game experiences
- Smooth arcade controls and stat progression
- Multiple genres: basketball, action, debate, sports, arcade, and future platformers
- Expandable structure so more games can be added quickly

How to run locally:
1. Clone the repo
2. Open `index.html` in a browser or use a local server:
   `python -m http.server 8000`
3. Visit `http://localhost:8000`

Main entry page:
- `index.html`

Playable game pages:
- `basketball-pro.html`
- `spider-game.html`
- `powerscaler.html`

This project is designed to grow into a multi-game hub with stronger game systems, upgrades, rosters, story modes, and additional arcade sections.
